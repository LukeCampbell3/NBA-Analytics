API

Research API

Authentication

Header: X-API-Key: nba_live_<prefix>_<secret>

Session users may call read endpoints with Authorization: Bearer <token>.

Endpoints

  • GET /api/safe-state/latest
  • GET /api/safe-state/cards
  • GET /api/players/simulations
  • GET /api/players/:playerId/simulation
  • GET /api/settlement/history
  • GET /api/model/status
  • GET /api/safe-state/export.csv (Pro/API)

Rate limits

Responses include X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset.

Response fields

All payloads include shadow_only, promotion_ready, production_behavior_changed, data_cutoff_date, and run_id.
